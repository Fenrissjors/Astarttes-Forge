# Astartes Forge v2.5.0 — Source & Edition Inspector

Adds a future-proof Source Adapter inspection layer. It reads New Recruit roster metadata (including explicit game-system edition/revision), fingerprints the ROSZ structure, reports unknown profile/characteristic fields, shows Chapter/detachment discovery and library fallbacks, and can export a machine-readable migration report.

No list-building data is duplicated: ROSZ remains authoritative and edition schemas only describe how to interpret/present it.
