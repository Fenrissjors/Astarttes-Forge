# Astartes Forge v2.9.2 — Functional Themes & Full Chapter Ornamentation

## Changes
- Card Material is now a real visual material selector: Classic, Aged, Weathered, Clean Vellum and Ice-bound parchment.
- Theme colour/material edits no longer mutate Chapter identity, preventing emblem fallback after customization.
- Chapter preset UI removes Crimson Fists, Flesh Tearers and Successor/Custom presets.
- Army Forge hides Leader/Support selectors when no eligible attachment exists.
- Leader choices show the selected Enhancement directly in the attachment dropdown.
- Space Wolves receive page-scale Fenrisian decoration: hanging ice, rune watermark, wolf-pelt panel and carved rune-bone ornament.
- Other supported Chapters receive broader page-scale chapter treatments rather than tiny abstract marks.
- v2.9.2 generic structure-aware Detachment Rule hierarchy is retained unchanged.

## Design rule
Decoration is presentation-only and must never alter roster data, Chapter detection, source provenance, or A4 fit decisions.
