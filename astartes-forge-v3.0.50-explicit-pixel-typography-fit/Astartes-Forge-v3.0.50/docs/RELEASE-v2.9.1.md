# Astartes Forge v2.9.1 — Illustrated Chapter Identity & Rules Layout

- Detachment rules now render from source hierarchy generically: prose, headings, named options, bullets and restrictions.
- The change applies to every detachment rule; no Saga-specific exception exists.
- Chapter emblem slots now load the actual published chapter heraldry via Lexicanum file redirects, with the Imperial Aquila as generic fallback.
- Decoration intensity slider removed; users keep simple on/off controls.
- Chapter ornament layers are fuller and recognisable rather than abstract symbols.
- Stratagem phase identity is reinforced by a phase-coloured outer stripe, spine stripe, subtitle treatment and header line.
- CP / emblem / turn blocks use true grid centering.
