# Astartes Forge v2.7.1 — Army Rule Resolver

## Changes

- Added a source-first, faction-aware Army Rule Resolver. Force-level army rules from New Recruit are now imported as the authoritative army-wide rule source.
- Black Templars therefore show **Templar Vows** and do not need a hard-coded Oath of Moment substitution.
- Precision validation accepts explicit numeric characteristic improvements such as AP improved by 1.
- No changes to datasheet, weapon, attachment, structure-aware or print behaviour.
