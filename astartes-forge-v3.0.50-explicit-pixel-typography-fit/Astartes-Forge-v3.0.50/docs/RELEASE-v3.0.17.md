# Astartes Forge v3.0.17 — Print Consistency

## Summary
v3.0.17 is a targeted print-layout refinement on top of v3.0.16.

## A5 Chapter emblem
- Removed the legacy `translateY(-50%)` inherited from the responsive datasheet emblem.
- The emblem now participates normally in the A5 flex title band and is vertically centred in the existing emblem box.
- Emblem size, title-band height, chapter palette and all A5 content geometry remain unchanged.

## Clean A4 consistency
- A4 without Rand Artwork now uses one vertical information flow for standalone units and attached/composite units.
- Standalone-unit profile, weapons, abilities, enhancement, rules and keywords appear consecutively from top to bottom, matching the presentation grammar already used by composed datasheets.
- A4 with artwork is unchanged.

## Unchanged
Space Wolves frame artwork/full-bleed crop, A5 artwork-free behavior, background variants, ROSZ import, rules/reference libraries and Forge Army Pack print flow.
