
# Astartes Forge v3.0.2 — Modular Codex Panels & Responsive A4 Preview

## Web preview
A4 datasheets are no longer laid directly into a responsive browser grid.
Each card keeps a physical 210×297 mm master canvas and is scaled inside a
dedicated preview shell, so multiple cards cannot overlap or acquire different
apparent sizes.

## Modular text panels
Stats, ranged weapons, melee weapons, abilities, rules, keywords and faction
keywords are now stable Codex text-panel types. Their visual construction is
constant; only their placement changes between Standard/Hero/Dense layouts.

## Illustrated frame
Space Wolves now uses substantial raster artwork pieces derived from the visual
benchmark: top frame, wolf/fur corner, left and right decorated rails, lower
frame and optional rune watermark. Artwork contains no live roster values.

## Data safety
No ROSZ importer, provenance, rules library or Source Integrity semantics were
intentionally changed.
