# Astartes Forge v3.0.16 — Print Layout Refinement

## Summary
v3.0.16 separates the physical A4 and A5 print presentations so each format can use the space properly.

## Print surfaces
- Background choices are now **Parchment**, **White** and **Chapter light**.
- White changes every light/parchment information surface to white, not only the page background.
- Parchment consistently restores parchment across the same information surfaces.
- Chapter light uses a pale Chapter-specific tint chosen for dark-text legibility.
- Coloured title bars, section headers and points blocks keep the Chapter palette for structure.

## A4
- Space Wolves A4 artwork from v3.0.15 is unchanged when the A4 artwork border is enabled.
- The v3.0.14 full-bleed 226 × 317 mm overscan remains unchanged.
- With artwork disabled, the clean datasheet expands to almost the complete 210 × 297 mm sheet instead of retaining the frame safe-zone.

## A5
- A5 is now permanently artwork-free; the retired A5 frame asset is no longer mounted or shipped.
- The A4 artwork toggle is hidden while A5 output is selected.
- A5 is rebuilt as a dedicated landscape datasheet rather than a scaled-down A4 page.
- Stats and weapons occupy the left information column; abilities and rules occupy the right column; keywords span the lower area.
- Chapter-colour title bars, weapon headers, profile strips and compact high-contrast boxes create a closer tabletop-datasheet hierarchy while keeping imported text live and readable.
- Two 210 × 148.5 mm A5 datasheets still compose one physical A4 print sheet.

## Unchanged
ROSZ import, rule/reference libraries, detachment validation, A4 Space Wolves artwork and Forge Army Pack print flow.
