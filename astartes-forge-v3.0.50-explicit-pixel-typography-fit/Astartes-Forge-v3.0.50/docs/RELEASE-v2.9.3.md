# Astartes Forge v2.9.3 — Illustrated Datasheet Framework

The visual layer is now data-driven in the same way as roster content. A Chapter key resolves one decoration pack, and each pack supplies any combination of five presentation slots: header, corner, footer, watermark and accent.

Space Wolves are the benchmark implementation and deliberately use large, asymmetric Fenrisian elements rather than small CSS marks. The supplied SVGs are original project assets inspired by the user-provided references: hanging ice, fur, carved rune bone, talismans and manuscript-like runes.

Other Chapters already have independent pack mappings, so adding richer artwork for one Chapter cannot leak into another.
