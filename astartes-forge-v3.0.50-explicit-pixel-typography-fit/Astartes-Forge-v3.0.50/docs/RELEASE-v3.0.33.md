# Astartes Forge v3.0.33 — A4 Chapter Frame Golden Standard

This release changes no approved artwork. It formalizes Space Wolves, Ultramarines and Blood Angels as the three locked A4 Golden Reference frames and introduces automated acceptance criteria for every future Chapter frame.

The authoritative rules are in `docs/design/A4-CHAPTER-FRAME-GOLD-STANDARD.json` and its companion Markdown document.
