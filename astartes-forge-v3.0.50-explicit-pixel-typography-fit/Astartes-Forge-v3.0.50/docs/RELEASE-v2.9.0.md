# Astartes Forge v2.9.0 — Chapter Identity & Card Design Engine

Presentation-only release on top of v2.8.2 Provenance-Aware Source Integrity.

## Highlights
- Warhammer-inspired Stratagem card layout with vertical phase spine, CP diamond and fixed WHEN / TARGET / EFFECT / RESTRICTION hierarchy.
- Army Rules render as clean bullet lists instead of repeated EFFECT labels.
- Detachment prose and sub-rules use explicit bullet hierarchy.
- Warm parchment card material, deeper banners, gradients and shadows.
- Chapter/faction emblem appears at the upper-right of every datasheet.
- Chapter-specific decoration packs (runes/ice/pelts, scales/scorching, laurel/Roman, chains/crosses, feathers, lightning, mechanical motifs, etc.).
- Theme tab adds master decoration toggle, emblem, weathering, banner depth and decoration intensity controls.
- Decorations remain non-layout-affecting overlays so dense A4 datasheets retain fit priority.

## Data guarantees
No importer, source graph, provenance, detachment library, attachment, weapon merge or source-integrity semantics were changed in this release.
