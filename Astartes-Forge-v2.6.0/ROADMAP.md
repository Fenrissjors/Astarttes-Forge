# Roadmap

Gold Master freezes the core importer/render/print architecture. Future v2.x work should primarily be:

- Chapter rules modules and regression rosters.
- Theme / visual refinements.
- Data updates following official Games Workshop releases.
- Bug fixes discovered by regression or real-game use.

Major importer changes should only be made when a New Recruit export demonstrates data that the current lossless source graph cannot preserve.
