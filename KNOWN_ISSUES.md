# Known Issues / Scope Boundaries

- Astartes Forge does not attempt to recreate the entire Games Workshop database. New Recruit ROSZ data is primary whenever it is present.
- Codex/app-only rule wording that is not present in a selected ROSZ export cannot always be independently verified from free official publications. Existing concise cards for the verified test set remain regression-tested; official public Faction Pack content and MFM metadata are cross-checked separately.
- Vengeful Hosts was published after the current v1.0 MFM snapshot used by this audit. Its rule identity is retained, while selected costs continue to come from New Recruit until matching official MFM metadata is available.
- Browser printing can vary slightly by browser/printer driver; the per-card A4 fit engine remains the authoritative print layout path.
