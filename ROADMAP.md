# Roadmap

v2.8.0 keeps the importer/render/print architecture frozen and extends content through data modules.

Next priorities:

- Verify all 12 v2.8.0 First Founding / generic expansion rosters in Batch Test Lab.
- Add a dedicated Deathwatch module from New Recruit fixtures.
- Continue theme / visual refinements only after content verification.
- Update edition schemas and reference metadata when New Recruit or Games Workshop changes source data.

Architecture rule:

> New Recruit decides what the roster can contain. Astartes Forge preserves, enriches and presents that data for fast tabletop reference and printing.

Major importer changes should only be made when a New Recruit export demonstrates data that the current lossless, structure-aware source graph cannot preserve.
