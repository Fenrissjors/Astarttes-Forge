# Astartes Forge v3.0.26 — Space Wolves Frame Rebuild

This release replaces the legacy/repaired Space Wolves A4 frame with the newly approved render.

## Frame rules
- 2480 × 3508 px A4 portrait asset
- exact 210 × 297 mm display; no renderer zoom or crop
- chapter-native transparency; no shared alpha mask
- one integrated title plaque
- content opening begins at the established title/body clearance
- footer opening tapers before the bottom ornament, matching the working Ultramarines/Blood Angels behavior
- full-bleed artwork reaches all four physical page edges
