# Astartes Forge v2.7.0 — Black Templars Module

## Added

Six Black Templars verification detachments:

1. Marshal's Household — Priority Assets — 1DP
2. The Living Miracle — Disruption — 1DP
3. Wrathful Procession — Take and Hold — 1DP
4. Companions of Vehemence — Purge the Foe — 2DP
5. Godhammer Assault Force — Purge the Foe — 2DP
6. Vindication Task Force — Priority Assets — 2DP

The module follows the same architecture as Dark Angels: selected Detachment Rules and roster facts are read from New Recruit; the Rules Library supplies concise printable Stratagem/Enhancement references when ROSZ does not include them.

## Current-data note

The original June 2026 Faction Pack announcement listed older dispositions for The Living Miracle and Godhammer Assault Force. The current New Recruit exports supplied for this release use Disruption and Purge the Foe respectively, matching later rules updates. Astartes Forge therefore uses the current ROSZ metadata for the imported army.
